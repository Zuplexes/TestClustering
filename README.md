# Image Clustering with Fuzzy C-Means (FCM)

โปรเจกต์นี้เป็นการจัดกลุ่มรูปภาพ (Image Clustering) โดยใช้อัลกอริทึม **Fuzzy C-Means (FCM)** ที่พัฒนาขึ้นจากสมการทางคณิตศาสตร์โดยตรงด้วย NumPy ร่วมกับ OpenCV และ Matplotlib เพื่อประมวลผลและแสดงผลลัพธ์การจัดกลุ่มของชุดข้อมูลรูปภาพ

## 📋 ความสามารถของโปรเจกต์
- **อ่านและเตรียมข้อมูลภาพอัตโนมัติ:** รองรับไฟล์นามสกุล `.jpg`, `.jpeg`, `.png` และ `.bmp` โดยแปลงภาพเป็น Grayscale และปรับขนาด (Resize) เป็น `32x32` พิกเซล พร้อมทำ Normalization
- **Fuzzy C-Means Clustering:** คำนวณค่า Membership Matrix ($\mu$) และจุดศูนย์กลางกลุ่ม (Cluster Centers) แบบวนซ้ำจนกว่าค่าความเปลี่ยนแปลงจะน้อยกว่าเกณฑ์ที่กำหนด (`1e-5`)
- **แสดงผลลัพธ์ (Visualization):** แสดงผลการจัดกลุ่มของแต่ละภาพทั้งทางหน้าจอ Console และกราฟรูปภาพด้วย Matplotlib

## 🛠️ เทคโนโลยีและไลบรารีที่ใช้
- **Python 3.x**
- **OpenCV (`opencv-python`)** - สำหรับอ่านและปรับขนาดรูปภาพ
- **NumPy (`numpy`)** - สำหรับการคำนวณเมทริกซ์และอัลกอริทึม Fuzzy C-Means
- **Matplotlib (`matplotlib`)** - สำหรับแสดงผลรูปภาพและกลุ่มที่ถูกจัดประเภท
